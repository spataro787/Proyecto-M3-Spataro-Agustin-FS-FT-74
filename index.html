Acerca del proyecto

Fantasy AI Chat es una Single Page Application desarrollada con HTML, CSS y JavaScript puro.

Utiliza Google Gemini API para conversar con distintos personajes de ficción manteniendo una personalidad propia.

  • Gandalf: sabio, tranquilo y misterioso.
  • Yoda: responde como un maestro Jedi.
  • Sherlock Holmes: responde utilizando lógica y deducción.
